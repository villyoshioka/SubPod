## Sub Pod って？

WordPress サイトのデータベースとファイルを、まるごとバックアップするプラグインです。

戻すときは、バックアップファイルをアップロードするだけです。別の環境へも戻せるので、PC の買い替えや、元の環境が動かなくなったときにも使えます。

---

## Sub Pod でできること

1. サイト全体のバックアップ: データベースとファイルをすべてバックアップします。ボタンひとつで実行できます。
2. 保存先を複数選択: 次の 3 つから、いくつでも選べます。どの保存先にも、設定した暗号化パスワードで暗号化したファイルを置きます。
   - 完了時にダウンロード: できたファイルをブラウザで受け取ります。受け取らなかったファイルはサイトに残しません。
   - 特定のディレクトリ: WordPress の外にあるフォルダへ保存します。
   - Cloudflare R2: Cloudflare のストレージへ送ります。
3. 復元: バックアップファイルをアップロードして、サイトを置き換えます。途中で失敗したら、元の状態へ戻します。
4. 別の環境への復元: データベースの接続先は今の環境のまま、URL とパスを新しい環境に合わせて書き換えます。
5. Carry Pod との連携: 当方のサイト変換プラグイン「[Carry Pod](https://github.com/villyoshioka/CarryPod)」（3.5.0 以降）の静的化の前に、自動でバックアップを取ります。バックアップに失敗したら、静的化は行いません。設定でオフにもできます。

---

## 想定環境について

[Local](https://localwp.com/) や [MAMP](https://www.mamp.info/)、[WordPress Studio](https://developer.wordpress.com/studio/) などを使って、自分の PC（ローカル）で WordPress を動かすスタイルを想定しています。

マルチサイトには対応していません。

---

## 使いかたの 3 ステップ

1. プラグインを入れる: [Releases](https://github.com/villyoshioka/SubPod/releases) から ZIP をダウンロードし、WordPress の「プラグイン」画面からインストールして有効化します。
2. 保存先と暗号化パスワードを決める: 管理メニューの「ツール → Sub Pod」を開き、「バックアップ設定」で保存先を選び、暗号化パスワードを入力して保存します。
3. バックアップする: 「今すぐバックアップ」を押します。

戻すときは、同じ画面の「復元」でファイルを選び、暗号化パスワードとログインパスワードを入力して実行します。
R2 のバックアップは、R2 のダッシュボードからダウンロードしたファイルを選びます。

## 注意事項

- 復元すると、今のサイトはデータベースもファイルも置き換わります。バックアップにはプラグインのコードも含まれるので、信頼できるファイルだけを使ってください。
- 暗号化パスワードは、必ず手元に控えてください。忘れると、バックアップは戻せません。変更しても、それまでのバックアップは前のパスワードのままです。
- 暗号化パスワードが設定されていないときは、バックアップを取りません。Carry Pod の自動実行では、バックアップを取らずに静的化します。
- 暗号化されていないバックアップ（1.0.x のダウンロードと特定のディレクトリのもの）は復元できません。サイトの秘密情報を取り出せる状態で入っているので、削除をおすすめします。
- バックアップには WordPress 本体も含まれます。古いバックアップを戻すと本体も古くなるので、戻したあとは WordPress を更新してください。
- Sub Pod は履歴を持ちません。古いバックアップの整理は、保存先で行ってください。
- 次のものはバックアップに含まれません。実行後に表示される案内やログで確認できます。
  - シンボリックリンクの先のファイル
  - データベースのビュー、トリガー、ルーチン
- Carry Pod の自動実行ではダウンロードは使われません。保存先がダウンロードだけのときは、バックアップを取らずに静的化します。
- 異なるデータベースシステムへの復元はできません。
- 別の環境へ復元すると、元の環境と同じ場所へ送らないよう、保存先の Cloudflare R2 と特定のディレクトリをオフにします。使うときは設定を確認してください。
- 復元の間、今のサイトは OS の一時フォルダへ退避します。途中で PC が落ちると、再起動で消えて元に戻せないことがあります。大事なサイトは先にバックアップを取ってください。
- 復元が途中で止まると、インストール画面と更新画面は閉じたままになります。手でサイトを元に戻したあと、`wp-content/install.php` を削除してください。

## プライバシーについて

このプラグインはあなたのサイトをバックアップ・復元するためだけに存在します。あなたのデータを勝手に集めたり、こっそり追跡したりすることは一切ありません。
